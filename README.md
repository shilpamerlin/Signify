# SignifyPro - App To Create Custom Email Signatures
  Create stunning email signatures in seconds with Signify! Choose from customizable templates, add your personal details,and make your emails stand out with unique designs
## Download load the app - https://apps.apple.com/us/app/signifypro/id6737203262
- **Swift**: SwiftUI
- **Architecture**: MVVM
- **Dependencies**: Firebase

## PreRequisties
**XCode**: 15.4


- User can register an account and once logged in the app will list all the sample templates 
- User can select the template 
- Once the template is selected user will be asked to provide the details to generate signature
- User can save the signature and can edit it if required
- Finally user will be able to download the signature
